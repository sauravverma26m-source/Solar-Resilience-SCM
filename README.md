## What this repository contains
| Folder / file | Contents |
|---|---|
| `src/solar_resilience_pipeline.py` | Single commented, seeded Python script: data generation -> damped Holt-Winters forecast -> supply-gap scenarios -> K-Means + PCA supplier clustering -> FIFO vs LP (HiGHS) scheduling -> figures |
| `data/synthetic/` | Input data (generated by the script): `demand_history.csv` (54 months), `suppliers.csv` (24 suppliers), `component_risk.csv`, `scheduling_inputs.csv` |
| `data/processed/` | Outputs: `forecast_24m.csv`, `deficit_sensitivity.csv`, `supplier_clusters.csv`, `schedule_baseline_fifo.csv`, `schedule_optimised_lp.csv`, `kpi_summary.csv` |
| `outputs/figures/` | PNG figures (incl. `report_fig4_pca.png`, `report_fig5_dashboard.png` used in the report) |
| `outputs/console_output.txt` | Console output of the reference run (reproduced in Annexure C of the report) |
| `prompts/prompt_logbook.csv` | Prompt logbook (prompt text, tool, output summary, usage, reflection) |
| `dashboard/` | Instructions to rebuild the Power BI dashboard from `data/processed/` |
| `docs/` | Report (`WAI_Report_Solar_Supply_Chain.docx`), data dictionary, calibration notes |

## How to run
```bash
pip install -r requirements.txt
python src/solar_resilience_pipeline.py
```
Runs in under a minute; all random draws are seeded, so every run reproduces the same results.

## Key results (reference run)
- Damped Holt-Winters (phi = 0.92) holdout MAPE 5.1% (undamped 6.6%, SARIMA 11.0%); module demand 58.9 GW (FY27), 60.6 GW (FY28)
- FY27 net domestic cell deficit 28.2 GW in the base case (80% utilisation); 17.4 GW in the most optimistic scenario
- K-Means (k = 3): 10 low-risk / 8 moderate / 6 elevated-risk suppliers; silhouette 0.20
- LP schedule: ALMM fill 76.5% -> 100%; 12-week contribution margin +Rs 22.0 Crore (+4.4%)

## Data disclosure
Confidential factory data (prices, lead times, change-over and scrap logs, supplier delivery records) are not public. **All input data are synthetic**, generated by seeded code and calibrated to the statistics in the report (Table 5) and to published policy and capacity figures (MNRE, DGTR, CEA, DGCIS, Mercom, SMM, TaiyangNews). Results are directional decision support, not transactional values. See `docs/calibration_notes.md`.
