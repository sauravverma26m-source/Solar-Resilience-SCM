# Power BI dashboard (rebuild instructions)
The `.pbix` file must be built in Power BI Desktop (it cannot be generated by the Python pipeline). Steps:
1. Get Data -> Text/CSV: import `data/processed/forecast_24m.csv`, `deficit_sensitivity.csv`, `supplier_clusters.csv`, `kpi_summary.csv`, `schedule_baseline_fifo.csv`, `schedule_optimised_lp.csv` and `data/synthetic/component_risk.csv`.
2. Build the six visuals shown in `outputs/figures/report_fig5_dashboard.png`: KPI cards; line + area (cell requirement vs supply); scatter of PC1/PC2 coloured by `tier`; component heatmap (matrix, conditional formatting); clustered bar (FIFO vs LP KPIs); scenario matrix (ramp x utilisation).
3. Save as `dashboard/solar_resilience.pbix` and commit it.
